⚙️ Paramètres de Transcription

Le mode Web Speech Natif fonctionne immédiatement sur iPad sans aucune configuration ni serveur.
Votre clé est stockée uniquement dans votre navigateur et n'est jamais transmise à un tiers.
Sélectionnez votre micro (AirPods, casque, micro USB). Note : En mode natif (sans clé), le micro actif suit automatiquement le micro principal de votre iPad ou PC (vos AirPods connectés).

📲 Installer Charly Transcri

🎤 Autoriser le Microphone

Le navigateur a besoin de votre autorisation pour écouter la voix et la transcrire.

Sur iPad (Safari) :

1. Touchez l'icône aA ou le cadenas à gauche dans la barre d'adresse.
2. Touchez Réglages du site web.
3. Réglez Microphone sur Autoriser.
4. Rechargez la page.

Sur PC (Chrome / Edge) :

1. Cliquez sur l'icône de réglages / cadenas à gauche de l'adresse URL.
2. Activez l'interrupteur Microphone.
3. Cliquez sur le bouton microphone à nouveau.
